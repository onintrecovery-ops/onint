# Builder Task Format

## Goal

One sentence describing the desired result.

## Context

Relevant project and user context.

## Acceptance criteria

- [ ] Criterion 1
- [ ] Criterion 2

## Constraints

Technical, security, budget, and compatibility constraints.

## Allowed actions

What the agent may change without additional approval.

## Required approvals

Actions that must be confirmed before execution.

## Validation

Commands, tests, or checks required before completion.

## Handoff

Report changed files, validation results, assumptions, risks, and next action.
